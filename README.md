# 校园碎片时间技能交换小程序

一个基于微信小程序的校园技能交换平台，主打"无金钱交易"的技能互换，贴合学生资源共享需求。

## How to Run

### 1. 环境准备

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 注册小程序账号，获取 AppID

### 2. 项目配置

1. 用微信开发者工具导入项目（选择项目根目录）
2. 修改 `project.config.json` 中的 `appid` 为你的小程序 AppID

### 3. 开发模式 vs 云开发模式

项目支持两种运行模式：

**开发模式（默认）**
- 在 `app.js` 中设置 `devMode = true`
- 使用本地模拟数据，无需配置云开发环境
- 适合快速预览和功能演示
- 登录状态通过本地存储保持

**云开发模式**
- 在 `app.js` 中设置 `devMode = false`
- 需要配置云开发环境（见下方说明）
- 数据存储在云端数据库

### 4. 云开发配置（可选）

如需使用云开发模式：

1. 在微信开发者工具中开通云开发
2. 创建云环境，获取环境ID
3. 修改 `app.js` 中的 `env` 为你的云开发环境ID
4. 创建以下数据库集合：
   - `users` - 用户集合
   - `skills` - 技能/需求集合
   - `appointments` - 预约集合
   - `evaluations` - 评价集合
5. 上传云函数：右键点击 `cloudfunctions` 目录下的每个云函数文件夹 → 上传并部署（云端安装依赖）

### 5. 运行项目

点击微信开发者工具的「编译」按钮即可运行。

**注意**：项目使用自定义 TabBar（emoji图标），无需额外添加图标文件。

## Services

本项目包含以下云函数服务：

| 云函数名称 | 功能描述 | 主要接口 |
|-----------|---------|---------|
| `login` | 用户登录服务 | 自动注册新用户、返回openid和用户信息 |
| `matchSkill` | 技能匹配算法服务 | 根据技能类型、校区、时间偏好进行智能匹配，信誉分加权排序 |
| `manageAppointment` | 预约管理服务 | 创建预约、更新状态、取消预约、获取预约列表（含防重复预约） |
| `submitEvaluation` | 评价与积分服务 | 提交评价、获取评价列表、计算并更新用户信誉分 |

### 云函数调用示例

```javascript
// 技能匹配
wx.cloud.callFunction({
  name: 'matchSkill',
  data: {
    type: 'findSkill',      // findSkill-找技能 / findNeed-找需求者
    category: 1,            // 技能分类ID
    campus: '东校区',        // 校区偏好
    availableTime: ['morning', 'afternoon'],  // 可用时间
    page: 1,
    pageSize: 10
  }
});

// 创建预约
wx.cloud.callFunction({
  name: 'manageAppointment',
  data: {
    action: 'create',
    data: {
      skillId: 'xxx',
      providerId: 'openid',
      appointmentTime: '2026-02-05 14:00',
      duration: 1,
      location: '图书馆',
      message: '你好，我想学习...'
    }
  }
});

// 提交评价
wx.cloud.callFunction({
  name: 'submitEvaluation',
  data: {
    action: 'submit',
    data: {
      appointmentId: 'xxx',
      rating: 5,
      comment: '非常棒的交换体验！',
      tags: ['耐心教学', '专业能力强']
    }
  }
});
```

3. 授权微信登录后即可使用所有功能
4. 登录状态会保存到本地存储，重新编译后仍保持登录

- 3个模拟用户（张三、李四、王五）

## 功能特点

### 核心功能

1. **技能/需求发布**
   - 发布技能（如"教PS修图"、"带练英语口语"）
   - 发布需求（如"求教Python爬虫"）
   - 设置交换时长（1小时技能换1小时）
   - 支持编辑和关闭已发布内容

2. **智能匹配**
   - 根据技能类型匹配
   - 根据校区偏好匹配
   - 根据时间偏好匹配
   - 信誉分加权排序

3. **在线预约**
   - 预约时间、地点、留言
   - 预约状态管理（待确认/已确认/已完成/已取消）
   - 防止同一时间被多人预约
   - 防止重复预约同一技能

4. **技能交换评价**
   - 五星评分
   - 标签评价（可多选）
   - 文字评价
   - 信誉分自动计算

5. **用户系统**
   - 微信一键登录
   - 登录状态本地持久化
   - 用户协议和隐私政策
   - 个人中心（我的技能、我的需求、我的评价）

### 云函数（技术亮点）

1. **login** - 用户登录云函数
   - 自动注册新用户
   - 返回用户信息和openid

2. **matchSkill** - 技能匹配算法云函数
   - 多维度匹配（技能类型、校区、时间）
   - 匹配分数计算
   - 信誉分加权

3. **manageAppointment** - 预约管理云函数
   - 创建预约（防止重复预约）
   - 更新预约状态
   - 状态流转校验

4. **submitEvaluation** - 评价与积分计算云函数
   - 提交评价
   - 信誉分计算（加权平均算法）
   - 自动更新用户信誉分

## 数据库权限

在云开发控制台配置集合权限：

```json
// users, skills 集合
{
  "read": true,
  "write": "doc._openid == auth.openid"
}

// appointments, evaluations 集合
{
  "read": "doc._openid == auth.openid || doc.providerId == auth.openid || doc.receiverId == auth.openid",
  "write": "doc._openid == auth.openid"
}
```
